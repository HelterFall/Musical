# Musical

Простой Android-плеер для личной музыкальной библиотеки.

## Возможности

- Добавление аудиофайлов через системный выбор файлов Android.
- Название песни, автор / исполнитель и текст песни.
- Создание плейлистов и добавление в них песен.
- Отдельный список авторов.
- Воспроизведение и пауза, просмотр текста.

## Важно: оригиналы аудиофайлов не копируются

При добавлении песни приложение получает системный URI выбранного файла и сохраняет только эту ссылку вместе с метаданными и текстом в локальной базе SQLite. Сам аудиофайл остаётся в исходном месте хранения.

Для доступа после перезапуска приложение запрашивает у Android постоянное разрешение чтения выбранного документа (Storage Access Framework). Если оригинал удалить, переместить так, что провайдер больше не сможет его найти, отозвать доступ или очистить данные Musical, песня может стать недоступной. В таком случае добавь файл снова.

## Сборка

1. Открой папку репозитория в Android Studio.
2. Дождись синхронизации Gradle.
3. Запусти конфигурацию app на Android-устройстве или эмуляторе.

Минимальная версия Android: 8.0 (API 26). Проект использует системный выбор документов, поэтому разрешение на чтение всей музыкальной библиотеки устройства не запрашивается.
